本项目是一个适用于 Minecraft (Fabric) 的模拟摄影模组，提供 8K 分辨率渲染、基于薄透镜公式的景深计算与真实测光曝光（虚化仅出现在拍摄的照片中，游戏预览不可见）。
建议在游玩前学习一些基础摄影知识，或面向具有较丰富摄影经验的玩家。

变更记录见 [CHANGELOG.md](CHANGELOG.md)。

## 技术特性
- **物理景深模拟**：薄透镜弥散圆公式 + 550nm 艾里斑衍射（平方和叠加）。支持 f/0.95–f/22，虚化随光圈值与物距动态变化；CoC 数组经 7×7 羽化平滑（仅拍摄的照片，预览中不可见）。
- **图像输出**：渲染分辨率 7680×4320（8K / 33MP），Iris 光影存在时从 tonemap 前的线性 HDR 缓冲读取（可配），否则回退主目标；导出 32-bit 浮点 TIFF（单张约 400 MiB），建议用 Lightroom/Darktable 等专业软件打开。
- **标准 EXIF 元数据**：主 IFD + Exif SubIFD，写入光圈、快门、ISO、测光/曝光程序、镜头型号与焦距、Software 等字段。
- **镜头与对焦系统**：定焦/变焦镜头，基于射线追踪的自动对焦（按下快门后 0.25s 合焦）与手动对焦；工作台配方调整焦距与最大光圈。
- **测光与曝光**：15×10 网格射线测光（评价/中央重点/局部/点测光），A+/P/Tv/Av/M/B 程序线，自动 EV 补偿。
- **中英双语**：完整 `zh_cn` 与 `en_us` 语言文件，取景器/消息/工具提示均可翻译。

## 镜头升级系统
将做好的镜头与升级材料一同放入工作台（**无序配方**，镜头 + 材料即可）：

1. **调整焦距（玻璃）**
   - 每个玻璃使焦距向下一档（13 → 20 → 24 → … → 1200mm），单次合成最多计 **4 个**。
   - **定焦镜头**：整体焦距后移，广角端随之改变。
   - **变焦镜头**：仅扩展长焦端，广角端锁定不变。变焦比上限 4.5x。

2. **功能升级（红石）**
   - **1 个红石**：激活【自动对焦】。
   - **2 个及以上红石**：同时激活【自动对焦】与【变焦功能】（变焦广角端固定为当前焦距）。

3. **光圈升级（铁锭/铁块）**
   - 铁锭 -0.1、铁块 -1.0，结果自动吸附到最近的标准光圈档位；单次最多计 4 锭 / 2 块。
   - *注意：光圈数值受镜头当前焦距段的物理上限限制。*

升级后镜头保留自定义名称等其他数据。

## 核心机制速览

### 相机结构
- **机身内置传感器**：Lumin F = 全画幅（36×24mm），Lumin H = 半画幅 APS-C（等效裁切 1.5x，同 ISO 噪点更多）。传感器不可更换。
- **镜头可装卸**：副手持镜头右键安装；**潜行 + 右键**卸下，镜头按原参数返还。卸下的镜头与升级配方处理的独立镜头是同一种物品。
- 相机参数保存在 typed 数据组件中，旧版本存档的相机/镜头会自动迁移，参数不丢。

### 取景器模式（↑/↓ 切换）
| 模式 | 行为 |
| :--- | :--- |
| **自动** | 全程序线（A+）：光圈/快门/ISO/白平衡全自动，4 秒长曝上限 |
| **照片** | 标准程序曝光（P），2 秒上限 |
| **人像** | 光圈优先（Av）：锁定最大光圈 + 自动对焦，背景虚化最明显 |
| **夜景** | 快门优先（Tv）：1/2s 长曝，低光高 ISO 噪点可见 |
| **电影** | 手动：1/48s 快门 + 上下黑边，模拟电影观感 |

### 曝光与测光
- 15×10 射线测光网格，`M` 键循环**评价 / 中央重点 / 局部 / 点测光**（改变取样范围与权重）。
- 曝光三角遵循真实公式（EV = log₂(N²/t) − log₂(ISO/100)），自动模式按「曝光误差 > 低 ISO > 慢快门 > f/4 附近」打分求解。
- 曝光补偿 ±5 档（1/3 档步进），预览与成片对称；手动参数偏离测光 >1 档时取景器红色警告。
- 自动对焦基于 256 格射线追踪，按下快门 0.25s 合焦；对焦距离受镜头焦距物理下限约束。

### 成片输出
- Iris 光影存在时从 **tonemap 前的线性 HDR 缓冲**读取成片（每个光影的缓冲号不同，见[配置](#配置)），无光影或未就绪时回退主目标（画面已有 tonemap，宽容度更低）。
- TIFF 内嵌完整 EXIF：光圈、快门、ISO、测光/曝光程序、镜头型号焦距、白平衡模式、Software。

## 操作说明
- **装备**：主手装备相机机身，副手装备镜头，右键安装（其他玩家可见安装动画）。
- **卸下镜头**：潜行 + 右键（副手留空），镜头按原参数返还。
- **快门**：鼠标左键（取景器激活时不会破坏方块）或 `P` 键。
- **取景器模式**：`↑` / `↓` 切换（自动 / 照片 / 人像 / 夜景 / 电影）。
- **参数**：`[` / `]` 选择参数，`←` / `→` 调整数值（曝光补偿、ISO、快门、白平衡、对焦、变焦镜头的焦距）。
- **测光模式**：`M` 键循环（评价 / 中央重点 / 局部 / 点测光）。
- **参数界面**：鼠标右键打开完整设置面板（佳能式布局：模式字母、快门/F 值/ISO 读数、EV 标尺），点击参数后滚轮/方向键调整，关闭时自动保存。
- 全部按键均可在「选项 → 按键绑定」中重新绑定（分类：相机模组）。

## 配置
配置文件 `config/camera-mod.json`（安装 Mod Menu 后可在 Mod Menu 中打开设置界面）：

| 选项 | 默认 | 说明 |
| :--- | :--- | :--- |
| `hideVanillaHud` | `true` | 取景器激活时隐藏原版热键栏/血条/准星（HUD 改版 mod 用户可关闭） |
| `uiStyle` | `Neon` | 取景器样式：`Neon`（现代无边框 HUD）/ `Classic`（佳能 EOS 式取景器：OVF 黑框 + 绿色数码管读数，模式字母 A+/P/Tv/Av/M、快门 1/80・0"5・2"、F 值、ISO、±3EV 标尺、AWB/K 白平衡、中央 AF 合焦框） |
| `meteringIntervalTicks` | `3` | 测光射线间隔 tick 数（1–5） |
| `settleFrames` | `4` | 8K 拍摄前等待 TAA 收敛的帧数 |
| `mmPerBlock` | `375` | 薄透镜模型的世界比例（mm/方块） |
| `irisHdrTarget` | `AUTO` | Iris HDR 缓冲：`AUTO` 解析当前光影包 final 程序的 `texture(colortexN)` 采样自动选定（Eclipse→colortex5，Complementary→colortex3 实测通过）；`0-15` 手动指定；`-1` 禁用 HDR 读取 |
| `filenamePrefix` | `camera_` | 保存文件名前缀 |

JVM 属性 `-Dcameramod.mmPerBlock / -Dcameramod.irisHdrTarget / -Dcameramod.settleFrames` 显式设置时仍可覆盖配置文件。

## 安装与运行说明
1. 下载 Release 中的 `.jar` 文件。
2. 将本模组与 `fabric-api` 一同放入 `.minecraft/mods` 文件夹。
3. **运行警告**：生成单张 8K TIFF 约 400 MiB 硬盘空间，建议至少分配 6 GiB 内存。按下快门后，画面切换到 8K 帧缓冲渲染数帧，随后 CPU 在后台线程完成景深与写盘（数秒到数十秒，期间可以继续游戏）；后台保存完成前重复拍摄会被忽略。

## 本地构建（中国大陆网络指南）

前置：JDK 21。仓库默认**官方源**，海外用户与 CI 零配置可直接构建；国内网络可按需启用项目级镜像：

**一键启用项目级镜像（loom 依赖 + Gradle 发行包）**

```bash
./scripts/enable-cn-mirrors.sh    # 只改本仓库，不影响 ~/.gradle 或其他项目
./scripts/disable-cn-mirrors.sh   # 恢复官方源
```

启用后会临时修改仓库内两个文件：

- `gradle.properties`：追加 BMCLAPI 的 `loom_*` 三行（Minecraft 库 / 资源 / 版本清单）；
- `gradle/wrapper/gradle-wrapper.properties`：Gradle 发行包改走腾讯云镜像，原文件备份为 `*.cn-backup`（已 gitignore）。

切换 wrapper 下载源会改变 Gradle 的缓存目录，首次启用/关闭时可能重新下载一次发行包。

**不要提交这些镜像配置**：GitHub Actions 在海外，走镜像反而更慢。`scripts/commit-lint.sh` 会检查暂存区，CI 也会跑 `--all`；`enable-cn-mirrors.sh` 会自动安装 hook，也可以手动执行：

```bash
./scripts/install-git-hooks.sh   # git config core.hooksPath .githooks
```

如果之前用过旧版脚本，`~/.gradle/gradle.properties` 里可能还有 `loom_*` 行；项目级配置会覆盖它们，建议手动删除，避免影响其他项目。

**Gradle 发行包下载失败时**（官方 `services.gradle.org` 会 307 到 GitHub Releases，部分网络返回 504）：推荐直接用上面的 `enable-cn-mirrors.sh`，它会把 wrapper 切到腾讯云镜像。也可以手动下载解压后绕过 wrapper：

```bash
curl -sL https://mirrors.cloud.tencent.com/gradle/gradle-9.5.1-bin.zip -o /tmp/gradle.zip
unzip /tmp/gradle.zip -d ~/tools/
~/tools/gradle-9.5.1/bin/gradle build    # 用它替代 ./gradlew
```

| 命令 | 作用 |
| :--- | :--- |
| `./gradlew build` | 构建发布 jar（`build/libs/camera-mod-<版本>.jar`） |
| `./gradlew runClient` | 启动开发客户端（只加载本模组，验证模型/HUD/拍摄） |
| `./gradlew runClient -PwithIrisDev` | 额外加载 Iris/Sodium/DH 调试光影集成（见下文已知限制） |
| `MP_PATH=<整合包> MP_RUNNER=<启动脚本> scripts/runModpack.sh` | 把最新 jar 装进整合包并启动（自动清理旧版本 jar） |

**无人值守自动测试（autoTest）**

```bash
timeout 300 ./gradlew runClient -PautoTest=true -PautoTestExports=2
```

进入标题画面后自动创建 `cameramod-auto-test-<uuid>` 世界（**第二次运行自动复用已有世界**），
等待加载并按「fps/tps/mspt 从波动到小范围浮动」判定稳定（采样进度会实时打到日志与屏幕上），
然后依次截图手持样式、Neon/Classic 两套 HUD，并按 Iris/DH 开关组合（Iris 走反射开关；
DH 存在性依据 mixin/日志判定并从中提取构建进度百分比）实际导出多档位参数的 8K TIFF
（普通模式、多快门、色温等，ISO/EV 保持自动）。产物在 `run/auto-test/`
（`shots/`、`exports/`、`metrics.csv`、`report.json`），**下次启动自动清空**。

对应 JVM 属性：`-Dcameramod.autoTest=<outDir|true>`（不传则关闭）、
`-Dcameramod.autoTest.exports=N`（每组合导出档位数，默认 6）、`-Dcameramod.autoTest.prefix=<世界前缀>`、
`-Dcameramod.autoTest.quit=false`（完成后不自动保存退出）。

**已实测的 DH+Iris 组合矩阵**（`timeout 900 ./gradlew runClient -PwithIrisDev=true -PautoTest=true -PautoTestExports=2`）：
Iris 1.8.8 / Sodium 0.6.9 / DH 3.3.3（满足 DH 2.3.0-b+）/ Complementary Reimagined r5.9.3，
`irisOn/Off × dhOn/Off` 四组合全部通过：HDR 从各包的场景缓冲读取（AUTO 自动检测）、8 张 TIFF + 12 张截图、Iris 开关走
官方 IrisApi.v0、DH 开关走 `quickEnableRendering`。测试结束自动保存退出；已知 DH 关闭 LOD 数据库
时可能卡住数十秒，AutoTest 会在 45s 后强制结束进程（存档在此之前已完成）。注意 DH 的 jar 较大，
`dev-mods/` 缓存下载建议用断点续传（本网络会掐断长连接）。

  - push 到 `main`/`master` → 自动构建并刷新 [Release · Dev Snapshot](https://github.com/echou114514/minecraft-camera-mod/releases/tag/dev)（预发布，永远最新）；

## 开发环境（`gradlew runClient`）
`./gradlew runClient` 默认只加载本模组（验证模型/HUD/拍摄）。调试光影集成时加 `-PwithIrisDev`：

- **运行时依赖**：Iris 1.8.14-beta.1、Sodium 0.8.13-beta.1、Distant Horizons 3.3.3 通过 `modRuntimeOnly` 由 Loom 重映射后加载；只用于开发环境，不进发布 jar。已知限制：Iris 的 dev 环境Mixin refmap 重映射存在问题，见 [TODO.md](TODO.md)。
- **测试光影**：Complementary Reimagined r5.9.3 自动放进 `run/shaderpacks` 并预选；HDR 源由 AUTO 自动检测（解析 final 程序 → colortex3）。
- 网络慢时把 jar / 光影 zip 预先放进项目根目录的 `dev-mods/`（已 gitignore），`prepareDevRun` 会优先使用本地缓存。
- `run/` 与 `dev-mods/` 都不进版本库；删除 `run/config/iris.properties` 可重新选择光影包。

**中国镜像**：仓库默认官方源。需要镜像加速时运行 `scripts/enable-cn-mirrors.sh`（项目级：loom + Gradle wrapper），恢复用 `scripts/disable-cn-mirrors.sh`；commit lint 会阻止镜像配置进入 CI。
