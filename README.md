本项目是一个适用于 Minecraft (Fabric) 的模拟摄影模组，提供 8K 分辨率渲染与基于物理公式的景深计算（仅拍摄的照片中可见，游戏预览不可见）。
建议在游玩前学习一些基础摄影知识或具有较丰富的摄影经验的人群游玩。

## 技术特性
- **物理景深模拟**：基于几何光学弥散圆公式计算。支持 F0.95 至 F22 等光圈档位，虚化程度随光圈值与物距动态变化。采用 3x3 卷积对 CoC 数组进行空间平滑处理（模糊为预期仿真效果而非渲染问题，仅限拍摄的照片，预览中不可见）。
- **图像输出**：渲染分辨率为 7680x4320（即8K），基于 RGBA16F 浮点容器存储颜色数据，导出 32-bit 浮点 TIFF 格式文件（单张数据量约 400 MiB），建议使用专业图像编辑软件打开（如LightRoom/DarkTable等，否则可能会无法查看）。
- **标准 EXIF 元数据写入**：遵循 TIFF/EXIF 规范，在文件二进制结构中构建主 IFD 与 Exif SubIFD，写入光圈、快门速度、ISO、测光模式、镜头型号及物理焦距等元数据。
- **镜头与对焦系统**：支持定焦与变焦镜头。具备基于射线追踪的自动对焦（触发延迟 5 ticks / 0.25 秒）与手动对焦模式。通过工作台特定配方可调整焦距与最大光圈数值。

## 镜头升级系统
将做好的镜头与升级材料一同放入工作台，以下配方为**无序配方**（随便怎么放都行，只要在格子里即可）：

1. **调整焦距 (加玻璃)**
   - 放入任意数量的玻璃。
   - 每增加 1 个玻璃，镜头焦距跳向下一档（13 -> 20 -> 24 -> ... -> 1200mm）。
   - **定焦镜头**：整体焦距后移，广角端随之改变。
   - **变焦镜头**：仅扩展长焦端，广角端锁定不变。受物理结构限制，变焦比上限为 4.5x。

2. **功能升级 (加红石，需分开放置)**
   - 放入特定数量的红石：
     - **1 个红石**：激活【自动对焦】（基于射线追踪，按下快门后 0.25 秒合焦）。
     - **2 个红石**：激活【变焦功能】（广角端固定为当前焦距）。
     - **3 个红石**：同时激活【自动对焦】与【变焦功能】。

3. **光圈升级 (加铁锭)**
   - 放入任意数量的铁锭或铁块：
     - **铁锭**：调最大光圈，并自动吸附至最近的物理标准光圈档位（例如 f/2.8 跳至 f/2.5）。
   - *注意：光圈数值受镜头当前焦距段的物理上限限制。*

## 操作说明
- **装备**：主手装备相机机身，副手装备镜头。
- **快门**：鼠标左键或 `P` 键触发。
- **参数界面**：鼠标右键打开相机参数设置面板，点击A或M按钮切换自动或手动（部分模式下将会有一部分参数被锁定，自动模式下若发现参数屏幕与实际参数不符则无需理会，以取景器参数为准），点击要调整的参数并使用鼠标滚轮调整。
- **变焦**：键盘 `上` / `下` 方向键（需装备带有变焦功能的镜头）。

## 安装与运行说明
1. 下载 Release 中的 `.jar` 文件。
2. 将本模组与上述三个前置模组一同放入 `.minecraft/mods` 文件夹。
3. **运行警告**：生成单张 8K TIFF 文件约占用 400 MiB 硬盘空间，运行期间建议至少分配6GiB内存或显存。按下快门后，CPU 执行景深计算与图像文件写入操作会导致主线程阻塞（根据硬件性能，耗时通常在数秒至十数秒之间），此期间客户端画面将冻结并显示纯色画面，属预期渲染行为，并非卡死，请等待保存完成。
